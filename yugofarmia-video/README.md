# Yugofarmia cinematic product film

A 47-second, 1920×1080 Remotion film for LinkedIn. The pacing and scene architecture are informed by the supplied reference video, while the brand system, copy, product story, interface capture, artwork, and soundtrack are original to Yugofarmia.

## Preview

```bash
npm install
npx remotion studio src/index.ts
```

## Render

```bash
npm run render
```

The public `capture/` assets are produced from the live Yugofarmia website by the project workflow before rendering.
