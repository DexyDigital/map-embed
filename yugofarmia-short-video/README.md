# Yugofarmia short LinkedIn video

A 21-second, 1920×1080 Remotion product film using the live Yugofarmia homepage, the canonical website wordmark, the website product imagery, verified latest published medians shown on the live site, and official source attributions.

## Sequence

1. Live homepage
2. Potatoes, tomatoes, cucumbers, and raw cow milk product carousel
3. Six verified price cards in original currencies and units
4. DZS, SORS, and SURS source attribution
5. “More former Yugoslavian countries coming soon”
6. Canonical logo and `yugofarmia.com`

## Commands

```bash
npm install
npm install --no-save playwright@1.55.0
npx playwright install chromium
node scripts/capture-assets.mjs
python scripts/audio.py
npm run typecheck
npm run render
npm run still
```
